## Task Manager

This is a simple Task Manager application I built using HTML, CSS and JavaScript.

It helps users add, edit and delete tasks and also allows them to set a priority for each task.

## Features

- Add tasks
- View tasks
- Edit tasks
- Delete tasks
- Set task priority as High, Medium or Low
- Save tasks using LocalStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Start adding tasks.

## Project Structure

task-manager/
- index.html
- script.js
- style.css
- README.md

## How data is stored

I used the browser's LocalStorage to save the tasks. Because of this, the tasks stay saved even after refreshing the page.
